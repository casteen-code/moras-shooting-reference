# Moras Shoot Reference Desk

Five original reference videos and 49 timed shots for the Moras production shoot.

- Open `index.html` for the main page.
- Open `English.html` for an English-first page.
- Use the language button to switch all shooting instructions between English and Chinese.
- Notes and captured-shot checkmarks are stored only in the current browser.

This is a buildless static site. GitHub Pages can publish from the root of the `main` branch. Keep `media/` beside the HTML files.
